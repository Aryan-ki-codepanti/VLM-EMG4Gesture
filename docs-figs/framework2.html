🎯 Prompting & Multimodal Reasoning Layer
Prompt structure adapted from the target paper:

1. Intent: Is the hand strained / relaxed? Is the hand sufficiently close to the object?
2. Object & Interaction: What object is present? What interaction is intended?
3. Grasp: What grasp type is appropriate for the object?
4. Context: Combine visual, EMG, EEG and language information.

Proposed status: EEG model, final fusion strategy and LLM selection are to be finalized after dataset and model feasibility analysis. PaliGemma is selected as the primary VLM candidate because it is the VLM used in the target paper. The EMG branch is based on the existing EMG-FAN implementation.
